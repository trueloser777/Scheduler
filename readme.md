# ИТ-Раунд, 2 этап. Чат-бот.
Телеграм взят в качестве платформы для чат-бота из-за его удобства.


**Стек**:
- PostgreSQL как база данных
- Python 3.13 как язык программирования
    * FastAPI + hypercorn — ASGI + server
    * APScheduler — отправка уведомлений о событиях
    * aiogram — Телеграм
    * asyncpg — PostgreSQL
    * Pillow (PIL) — отправка расписания в графическом виде
    * pydantic — модели

**Известные проблемы:**
- Используемая временная зона не UTC, а наивная (naive), что может привести к проблемам


**Что можно доработать:**
- В `schedule.notify_about_events` можно получать все данные за раз, используя JOIN
- Добавить возможность пользователю выбирать его временную зону
- Добавить WebApp/сайт для просмотра и управления расписанием (добавить эндпоинты для API, сервер уже запускается)


**Подготовка:**
0. Необходимо создать бота через t.me/botfather, поднять PostgreSQL, создать пользователя и базу данных
1. Настройки
    - Скопировать файлы из config_templates/
    - Убрать .template в конце
    - Заменить TO_BE_EDITED на необходимые данные
        * В yoyo.ini данные от БД
        * config.json, `telegram.bot_token` получается через t.me/botfather
        * config.json, `owner_telegram_id` можно получить через t.me/getmy_idbot
2. Окружение (актуально для Windows)
    - Создать виртуальное окружение (venv): `py -m venv venv/`
    - Войти в виртуальное окружение: `./venv/Scripts/activate`
    - Установить необходимые зависимости: `py -m pip install -r requirements.txt`
3. Миграции: `yoyo apply` после пункта 2

**Запуск**: `py src/main.py`

**Функции бота, которые можно выделить:**
- "Угадывание" и уточнение того, что хочет пользователь:
    * Если он указал только время, значит, возможно, событие сегодня?
    * Если он отправил только /add, значит, стоит у него спросить название и описание
    * Если он отправил только название, значит, стоит у него спросить дату и время
- Расписание в виде изображения, генерируемое через PIL
- Огромные возможности для расширения:
    * Есть разделение на виды событий и возможность подписаться на отдельные
    * Есть разделение на публичные и приватные события
    * Проект полностью готов к добавлению API
    * Новый функционал и внесение изменений в БД - легко
    * Есть настройки для каждого из пользователей (предпочтения)
    * И многое другое
